# Codex Context for Rant and Heal V2

This file serves as a high-level summary of the Rant and Heal V2 project. Review this before making architectural or deep codebase changes.

## 1. Tech Stack
- **Framework**: Next.js App Router (`/app`)
- **Backend/Auth**: Firebase (Auth, Firestore)
- **AI Integration**: Google Gemini (via `@google/genai`)
- **Styling**: Tailwind CSS (Radiant Brutalism aesthetic)

## 2. Core Architecture
- **Identity Tier**: `users` collection in Firestore. Manages roles (`USER`, `THERAPIST`, `ADMIN`).
- **Professional Tier**: `therapists` collection. Public applicants submit `PENDING` profiles; only a Firebase Admin-custom-claim reviewer can make a profile `VERIFIED` and grant the `THERAPIST` role.
- **Relationship Tier**: `connections` collection. 1:1 patient-therapist handshake (`PENDING`, `ACTIVE`, `REJECTED`, `REVOKED`).
- **Service Layer**:
  - `src/services/`: Client-side Firebase helpers.
  - `src/server/`: Privileged Admin SDK integrations and Gemini handlers.

## 3. Key Features & Locations
- **Momo AI Guide**: Server-owned chat history. Client calls `/api/momo/chat`, server manages Gemini and Firestore writes. Video/voice uses `/api/momo/live-token`.
- **Momo Safety Interceptor v0.1**: Server-side phrase screen in `/api/momo/chat` and `/api/momo/transcript`. High-confidence direct self-harm or harm-to-others signals bypass Gemini, save fixed support copy, create an Admin-only `users/{uid}/safety_events/{eventId}` record, and route the client to `/crisis`. Text is protected pre-generation; voice is only protected after a completed transcript, not in real time.
- **Therapy MVP**: 
  - Patient routes: `/therapy` (find therapist, connection status), `/therapy/chat/[therapistId]` (chat room), `/therapy/session/[sessionId]` (video session).
  - Therapist routes: `/portal` (pending requests), `/patients` (roster), `/messages` (conversation threads), `/session/[sessionId]` (video session).
  - Calls are created and transitioned through authenticated route handlers. Sessions have explicit caller/recipient fields and a per-connection transaction lock; Firestore is used for participant-scoped WebRTC signals. Optional TURN configuration is released only to active participants by `/api/therapy/ice-servers`.
- **UI Components**: Located in `src/components/` (divided into `ui/`, `forms/`, `shared/`, `layout/`).

## 4. Known Issues / Current Work
- **Safety Protocol**: v0.1 is provisional keyword screening, not a clinical assessment. It needs Shubhangi/clinician-approved risk levels, localized response copy, a verified resource directory, escalation ownership, and English/Nepali/romanized Nepali evaluation cases before launch.
- **Therapy Call System**: Caller/recipient state and server-owned call transitions are implemented. The remaining launch blocker is TURN configuration and two-browser end-to-end testing across real networks.
